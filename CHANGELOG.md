# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-06-21

### ✨ Adicionado
- Interface completa para criação de propostas comerciais
- Formulário intuitivo com validação de campos obrigatórios
- Cálculo automático de valores (subtotal, desconto, total)
- Visualização profissional da proposta antes de gerar PDF
- Exportação de propostas em formato PDF
- Design moderno e responsivo com Tailwind CSS
- Suporte para múltiplos serviços com cálculo individual
- Campos específicos para profissionais autônomos
- Seção de dados do profissional e cliente
- Seção de condições (pagamento, garantia, observações)
- Número de proposta gerado automaticamente
- Validação de datas (proposta e validade)
- Opções de profissão pré-definidas (Pedreiro, Marceneiro, Eletricista, etc.)
- Diferentes unidades de medida (un, m², m, hora, dia)

### 📚 Documentação
- README.md completo com instruções de uso
- QUICKSTART.md para início rápido
- EXEMPLOS.md com casos de uso reais
- DEPLOY.md com guia de deploy para várias plataformas
- Comentários no código para facilitar manutenção

### 🎨 Design
- Cabeçalho com logo e título da aplicação
- Formulário organizado em seções claras
- Preview da proposta com layout profissional
- Botões de ação bem posicionados
- Cores e espaçamentos consistentes
- Ícones do Lucide React para melhor UX

### 🔧 Técnico
- Next.js 15 com App Router
- TypeScript para tipagem forte
- Tailwind CSS para estilização
- jsPDF e html2canvas para geração de PDF
- ESLint para qualidade de código
- Configuração VS Code com extensões recomendadas
