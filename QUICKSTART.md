# Guia de Início Rápido - PropostaPro

## 🚀 Começar em 3 passos

### 1. Instalar Dependências
```bash
npm install
```

### 2. Executar o Projeto
```bash
npm run dev
```

### 3. Acessar no Navegador
Abra [http://localhost:3000](http://localhost:3000)

## 📝 Como Usar

1. **Preencha seus dados** (nome, profissão, contato)
2. **Adicione os dados do cliente**
3. **Descreva o projeto** que será realizado
4. **Liste os serviços** com quantidades e valores
5. **Defina condições** de pagamento e garantia
6. **Gere a proposta** e baixe em PDF

## 🎨 Dicas de Uso

- Use o botão "+ Adicionar Serviço" para incluir múltiplos itens
- O cálculo dos totais é feito automaticamente
- Você pode voltar e editar antes de gerar o PDF
- O número da proposta é gerado automaticamente

## 🆘 Problemas Comuns

**Porta em uso?**
```bash
# O Next.js usará automaticamente a próxima porta disponível
```

**Erro ao gerar PDF?**

- Tente recarregar a página
